## Purpose

服务端的 React 网页前端：实时展示最新截图的分析进度与结果，提供历史题目列表与详情回顾，以及服务端配置界面（端口、LLM 供应商、并发上限），是解答内容的唯一展示端。

## ADDED Requirements

### Requirement: 最新会话实时视图

网页前端 SHALL 默认展示最新 session 的状态与内容：分析中显示进行状态，完成后展示题型、解答、思路与代码（代码需有语法高亮与格式化展示）。前端 MUST 通过服务端推送（SSE）实时更新，无需手动刷新。

#### Scenario: 新截图到达时切换到最新会话

- **WHEN** 用户正在浏览页面时新截图到达
- **THEN** 页面主视图切换到新 session 并显示其进行状态；正在浏览历史记录的用户视图不被强制打断，改以可见提示告知新题到达

#### Scenario: 分析完成实时呈现

- **WHEN** 当前展示的 session 分析完成
- **THEN** 页面在数秒内无刷新呈现完整解答内容；编程题的代码块带语法高亮

### Requirement: 历史题目浏览

网页前端 SHALL 提供历史题目侧边列表（时间倒序，含题型与时间戳摘要），点击任一条目 MUST 在主视图展示该题的完整记录（截图、题型、解答、代码）。浏览历史不打断任何进行中的分析。

#### Scenario: 回顾历史题目

- **WHEN** 用户点击侧边列表中的一条历史题目
- **THEN** 主视图展示该题的截图原图与完整解答内容

#### Scenario: 历史分析在后台完成

- **WHEN** 用户浏览页面期间某个旧 session 在后台完成分析
- **THEN** 侧边列表中该条目状态更新为已完成，当前浏览视图不被打断

### Requirement: 服务端配置界面

网页前端 SHALL 提供服务端配置界面， MUST 包含：监听端口、LLM 供应商管理（增删改、协议类型、设为生效）、分析并发上限。除端口外的配置修改 MUST 即时生效；端口修改提示需重启服务端。

#### Scenario: 修改并发上限

- **WHEN** 用户在配置界面修改最大并发数并保存
- **THEN** 新的上限立即约束后续 session 的调度

#### Scenario: 配置供应商并设为生效

- **WHEN** 用户在配置界面新增供应商并设为生效
- **THEN** 后续新 session 使用该供应商发起分析

### Requirement: 构建与部署形态

网页前端 SHALL 以 React + 构建工具产出静态资源，由 Node 服务端进程直接托管，局域网内任一设备可通过浏览器访问。前端工程结构 MUST 便于后续迁移到桌面应用壳（Tauri）。

#### Scenario: 局域网访问

- **WHEN** 局域网内另一台设备的浏览器访问服务端地址
- **THEN** 页面正常加载，实时推送、历史列表与配置界面均可用
