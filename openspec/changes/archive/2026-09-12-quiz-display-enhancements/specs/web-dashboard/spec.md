# Delta: web-dashboard

## MODIFIED Requirements

### Requirement: 最新会话实时视图

网页前端 SHALL 默认展示最新 session 的状态与内容：分析中显示进行状态，完成后展示题型、题旨标题（如"选择题——求二叉树最大深度"；题旨为空时仅显示题型）、解答、思路与代码（代码需有语法高亮与格式化展示），并展示本次分析的耗时（从截图到达到分析完成）。前端 MUST 通过服务端推送（SSE）实时更新，无需手动刷新。

#### Scenario: 新截图到达时切换到最新会话

- **WHEN** 用户正在浏览页面时新截图到达
- **THEN** 页面主视图切换到新 session 并显示其进行状态；正在浏览历史记录的用户视图不被强制打断，改以可见提示告知新题到达

#### Scenario: 分析完成实时呈现

- **WHEN** 当前展示的 session 分析完成
- **THEN** 页面在数秒内无刷新呈现完整解答内容（含题旨标题与分析耗时）；编程题的代码块带语法高亮

### Requirement: 历史题目浏览

网页前端 SHALL 提供历史题目侧边列表（时间倒序，摘要含题型、题旨标题与时间戳，题旨为空时仅显示题型），点击任一条目 MUST 在主视图展示该题的完整记录（截图、题型、解答、代码）。浏览历史不打断任何进行中的分析。

#### Scenario: 回顾历史题目

- **WHEN** 用户点击侧边列表中的一条历史题目
- **THEN** 主视图展示该题的截图原图与完整解答内容（含题旨标题与分析耗时）

#### Scenario: 历史分析在后台完成

- **WHEN** 用户浏览页面期间某个旧 session 在后台完成分析
- **THEN** 侧边列表中该条目状态更新为已完成，当前浏览视图不被打断

## ADDED Requirements

### Requirement: 答题区宽度调整

网页前端的答题区（会话详情阅读列）SHALL 支持用户拖拽调整宽度：拖动答题区侧缘手柄时列宽按双侧对称方式增减（左右边缘镜像外扩或内收，保持居中），宽度 MUST 钳制在一个最小值与最大值之间（不小于约 600px、不超过约 1280px）。调整后的宽度 MUST 在当前浏览端持久保持（下次打开生效），MUST NOT 写入服务端配置。窄屏布局（侧栏抽屉形态）下 MUST 不出现宽度手柄。

#### Scenario: 对称拖拽调整宽度

- **WHEN** 用户按住答题区侧缘手柄向右拖动一段距离
- **THEN** 答题区左右边缘同时向外扩展相同距离，列宽增大且保持居中，不超过最大宽度

#### Scenario: 宽度持久保持

- **WHEN** 用户调整过答题区宽度后刷新页面或重新打开看板
- **THEN** 答题区以上次调整的宽度呈现

#### Scenario: 窄屏禁用

- **WHEN** 视口宽度处于窄屏（抽屉布局）范围
- **THEN** 不显示宽度手柄，答题区为单列自适应宽度
